# Preference Grouping Frontend

Vue 3 + Vite app for the Preference-based Grouping slide type. Three entry
routes render from one bundle: `/:type/canvas/:slideId` (presenter tally +
group reveal), `/:type/settings/:slideId` (group-size config), and
`/:type/audience/:slideId` (peer picker + personal group reveal).

See the app-level `README.md` for the full flow.

```bash
npm run dev
npm run build
```
